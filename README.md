# Hoc Python tu dau

Du an nho de bat dau hoc Python bang cach chay va sua mot chuong trinh that.
Khong can cai them thu vien.

## Bat dau tren macOS

1. Kiem tra Python 3 da duoc cai dat:

	```sh
	python3 --version
	```

2. Mo thu muc du an trong VS Code.
3. Mo terminal trong VS Code va chay:

	```sh
	python3 main.py
	```

4. Nhap hai so khi chuong trinh hoi. Vi du: `12` va `3.5`.

## Ban se gap gi trong bai dau

- `input()` doc gia tri ban nhap.
- `float()` doi chuoi thanh so co the tinh toan.
- Bien luu cac gia tri de dung lai.
- Dau `+` cong hai so.
- `print()` va f-string hien thi ket qua.

Mo `main.py`, thu doi phep cong thanh phep tru `-`, nhan `*`, hoac chia `/`.
Sau do hay thu nhap so am va so thap phan.

## Lo trinh goi y

1. Bien va cac kieu du lieu: `str`, `int`, `float`, `bool`.
2. Nhap va in du lieu: `input()`, `print()`.
3. Re nhanh: `if`, `elif`, `else`.
4. Lap: `for`, `while`.
5. Ham: `def`, tham so va gia tri tra ve.
6. Danh sach va tu dien: `list`, `dict`.

Moi lan hoc, hay tao mot tep moi nhu `bai_02.py` de giu lai bai tap truoc.
